# 빈 강의실 현황판 — 국립순천대학교

지금 이 시간, 어느 강의실이 비어있는지 한눈에 보여주는 웹앱입니다.

## 반영된 데이터

- **출처**: 순천대학교 수업시간표 조회 시스템 (stis1.scnu.ac.kr)
- **기준 학기**: 2026학년도 2학기
- **대상 단과대학** (6개)
  - 본부직속 (142강좌)
  - 그린스마트팜스쿨 (210강좌)
  - 애니메이션·문화콘텐츠스쿨 (350강좌)
  - 우주항공·첨단소재 스쿨 (206강좌)
  - 사범대학 (188강좌)
  - 약학대학 (50강좌)
- **집계 결과**: 20개 건물, 324개 강의실

## 기능

- 현재 시각·요일 기준으로 강의실별 상태를 3단계로 자동 판정
  - **비어있음**(초록) — 지금 바로 쓸 수 있음
  - **곧 수업**(노랑) — 쉬는시간이지만 다음 교시에 수업이 잡혀 있음
  - **사용 중**(빨강) — 지금 수업이 진행 중
- **즐겨찾기** — 강의실 카드의 별을 눌러 자주 가는 강의실만 따로 모아보기
  (브라우저에 저장되어 다음에 접속해도 유지됩니다)
- 건물별 탭 (건물마다 `비어있는 수 / 전체 수` 표시)
- 강의실 번호·건물명 검색
- "빈 강의실만 보기" 필터
- 비어있는 방은 다음 수업이 몇 교시부터인지 함께 표시
- 일요일에는 수업이 없으므로 전체를 빈 강의실로 안내

### 쉬는시간 처리

수업과 수업 사이(예: 09:50~10:00)에는 진행 중인 수업이 없어 모든 강의실이
비어 보이는 문제가 있었습니다. 이 시간대에는 **다음에 시작할 교시**를 찾아,
그 교시에 수업이 있는 강의실을 노란색 "곧 수업"으로 구분하고
`5분 뒤 2교시 수업 시작`처럼 남은 시간을 함께 알려줍니다.

```bash
npm install
npm run dev
```

http://localhost:3000 접속

## Vercel 배포

1. GitHub 저장소로 업로드

   ```bash
   git init
   git add .
   git commit -m "빈 강의실 현황판"
   git branch -M main
   git remote add origin <본인 GitHub 저장소 주소>
   git push -u origin main
   ```

2. https://vercel.com/new 접속 → GitHub 연결 → 저장소 선택
3. Framework이 자동으로 **Next.js**로 인식됩니다. 그대로 **Deploy** 클릭
4. `https://프로젝트이름.vercel.app` 으로 접속

## 데이터 갱신 방법

학기가 바뀌면 `data/rooms.js` 의 `BUILDINGS` 배열만 교체하면 됩니다.

```js
{
  name: "E8호관",              // 건물명
  rooms: [
    {
      no: "315호",             // 강의실 번호
      schedule: {
        월: [2, 3, 4, 6, 7, 8],  // 그 요일에 수업이 있는 교시 번호
        화: [1, 2, 3, 6, 7, 8],
        수: [2, 3, 4, 6, 7, 8],
        목: [1, 2, 3, 6, 7, 8],
        금: [6, 7, 8],
        토: [],
      },
    },
  ],
}
```

교시 ↔ 실제 시간 매핑은 같은 파일의 `PERIODS` 에서 관리합니다.
주간은 1~10교시(09:00~18:50), 야간은 11~16교시(18:00~22:55) 기준입니다.
